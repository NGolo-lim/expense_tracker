# 📊 Personal Expense Tracker (Трекер Личных Финансов)

Веб-приложение для удобного учёта, аналитики и фильтрации личных расходов, разработанное на **Python (Flask)** и задеплоенное на платформе **Render**.

🚀 Живая демо-версия: [https://expense-tracker-ftkf.onrender.com](https://expense-tracker-ftkf.onrender.com)

🌟 Основные возможности
Управление расходами (CRUD): Быстрое добавление, просмотр и удаление записей о тратах.
Динамическая фильтрация:
  * По категориям расходов.
  * По конкретному дню или месяцу.
  * По произвольному диапазону дат (SQL `BETWEEN` & `LIKE`).
Визуализация данных: Интерактивные диаграммы и графики расходов с помощью **Chart.js**.
Адаптивный UI: Современный и удобный интерфейс на **Bootstrap 5** с динамическими полями на JavaScript.

🛠 Технологический стек

Backend: Python 3, Flask, Gunicorn
Database: SQLite
Frontend: HTML5, CSS3, JavaScript, Bootstrap 5, Chart.js
Deployment & CI/CD: Git, GitHub, Render.com
